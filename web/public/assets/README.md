# Game Assets Directory

This directory contains external game assets (sprites, tiles, UI elements).

## Directory Structure

- `tiles/` - Ground tiles, water, roads (96×48 isometric)
- `buildings/` - Building sprites (cottage, well, tent, crate, etc.)
- `crops/` - Crop and plant sprites
- `ui/` - UI elements (buttons, panels, icons)
- `icons/` - Small icons for resources, tools, etc.
- `manifest.json` - Asset manifest (auto-generated by download script)

## Quick Start

1. **Download assets** using the helper script:
   ```bash
   cd web
   node scripts/assets/downloadAssets.mjs
   ```

2. **Or manually download** from recommended sources:
   - [Kenney.nl](https://kenney.nl/assets) - CC0 assets (no attribution required)
   - [OpenGameArt.org](https://opengameart.org) - Various licenses
   - [Itch.io Free Assets](https://itch.io/game-assets/free) - Various licenses

3. **Place assets** in the appropriate subdirectories

4. **Update CREDITS.md** with attribution for CC-BY assets

## Asset Requirements

### Tiles (96×48 pixels)
- Format: PNG with transparency
- Naming: `tile-{name}.png` (e.g., `tile-grass.png`, `tile-water.png`)

### Buildings
- Format: PNG with transparency
- Naming: `building-{name}.png` (e.g., `building-cottage.png`)

### Crops
- Format: PNG with transparency
- Naming: `crop-{name}.png` (e.g., `crop-wheat.png`)

## Integration

The game will automatically load assets from this directory if they exist. If assets are not found, the game will fall back to programmatic generation (current behavior).

See `Docs/ASSET_INTEGRATION.md` for detailed integration instructions.
