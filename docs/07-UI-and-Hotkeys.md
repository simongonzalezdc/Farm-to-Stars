# UI & Hotkeys

| Panel | Key | Purpose |
|---|---|---|
| Build Panel | **B** | Place buildings / zones |
| Budget Panel | **F1** | Income, expenses, tax sliders |
| City Panel | **C** | City yields & queue |
| Tech Panel | **T** | Research and tree |
| Empire Panel | **E** | Factions, treaties |
| Overlays | **1–5** | Power, Water, Land Value, Traffic, FOW |

- Use **Myra** for layout and **ImGui.NET** for debug inspectors.
- Overlay rendering via `Heatmap<T>` and `SpriteBatch` (no custom shaders required).
