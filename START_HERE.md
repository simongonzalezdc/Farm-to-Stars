# 🎮 START HERE - Farm to Stars

## ⚡ Super Easy Way to Run

### Option 1: Double-Click (Easiest!)
1. **Double-click `run.command`** in Finder
2. Terminal opens automatically
3. Game launches!

### Option 2: Terminal
```bash
./run.sh
```

That's it! The script does everything:
- ✅ Checks for .NET SDK
- ✅ Installs it if needed
- ✅ Restores packages
- ✅ Builds the project
- ✅ Runs the game

## 🎮 Controls

- **WASD** - Move camera
- **Mouse Wheel** - Zoom in/out
- **ESC** - Exit game

## 📋 What You Need

- macOS (tested on macOS 14+)
- Homebrew (for auto-installation) OR .NET 8 SDK installed manually

The script will install .NET SDK automatically if you have Homebrew!

## 🐛 Problems?

### Script won't run?
```bash
chmod +x run.sh
./run.sh
```

### Need to install manually?
See `INSTALL.md` for detailed instructions.

### Still stuck?
See `README.md` for full documentation.

## 🎯 What to Expect

When the game runs:
- Game window (1280x720) opens
- Dark green background with grid
- White square entities visible
- FPS counter in bottom-left
- UI panel in top-left
