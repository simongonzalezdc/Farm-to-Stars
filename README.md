# Farm-to-Stars Pivot

AI-driven grand strategy game. A cozy civilization builder powered by narrative AI.

## Quick Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Project Structure

```
src/
├── ai/              # AI provider layer
├── game/            # Core game logic
│   ├── scenario/    # Scenario definitions
│   ├── state/       # Game state management
│   └── decisions/   # Decision engine
├── ui/              # React components
│   ├── map/         # Strategic map
│   ├── events/      # Event cards
│   └── hud/         # HUD elements
└── data/            # Data files
```
