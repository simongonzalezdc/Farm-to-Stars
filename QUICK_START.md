# Quick Start - Farm to Stars

## Fastest Way to Test

### 1. Install .NET 8 SDK (if not installed)

```bash
brew install --cask dotnet-sdk
```

### 2. Navigate and Run

```bash
cd "/Users/simongonzalezdecruz/Desktop/Farm to Stars/Game"
dotnet restore
dotnet run
```

That's it! The game should launch.

## What to Expect

- Game window opens (1280x720)
- Dark green background with grid
- White square entities visible
- FPS counter in bottom-left
- UI panel in top-left

## Controls

- **WASD**: Move camera
- **Mouse Wheel**: Zoom
- **ESC**: Exit

## If It Doesn't Work

See `TESTING.md` for detailed troubleshooting.
